# 🦷 BrightSmile Dental – Website UI

A modern, responsive dental clinic website designed with a focus on clean UI, smooth interactions, and a premium user experience.

---

## ✨ Features

* 📱 Fully responsive (mobile-first design)
* 🎨 Clean, modern UI (SaaS-inspired)
* ⚡ Smooth hover & micro-interactions
* 🔄 Before/After comparison slider
* 📋 Interactive forms and service selection
* 💬 FAQ accordion (Notion/Stripe-style)
* 💳 Financing & insurance sections
* 📞 Clear CTAs (Book Now, Contact, etc.)

---

## 🧠 Design Approach

This project focuses on:

* Consistent spacing and layout system
* Subtle motion and interaction design
* Clean typography and visual hierarchy
* Avoiding heavy UI (minimal + premium feel)

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla)

## 📱 Responsive Design
